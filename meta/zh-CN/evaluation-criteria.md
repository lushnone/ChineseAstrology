# 收录说明（不是评分榜）

本仓库是 **名录**；下面只约束「什么能进清单、字段怎么填 honest」。

## 建议填的字段

| 字段 | 用途 |
|------|------|
| `name` | 产品对外名称 |
| `urls` | 官网、商店链接 |
| `features` | 功能列表（客观描述） |
| `i18n.*.summary` | 一句话：做什么用 |
| `pricing` | 免费/订阅等（看公开页面） |
| `locales_supported` | 界面语言 |
| `last_verified` | 你最后一次确认还能用的日期 |

## 可选：`scores`

1–5 分** entirely 可选**，仅作贡献者个人备注；**仓库不维护总榜、不选「最佳」**。

## 验证

- 自己点过链接或装过 App 再写 `last_verified`  
- 功能写产品在页面上声称的；不知道的放 `notes`，别猜算法门派  

## 收录 / 归档

**收录：** 能打开、和玄学工具有关、信息基本真实。  
**归档：** 死链、下架、明显钓鱼/ spam。

## 措辞

`name` / `summary` 里避免「第一」「最准」；不写解读结论。
